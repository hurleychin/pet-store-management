# 0001 用「价目行 × 服务分类」替换平铺服务项目表

- 状态：已接受
- 日期：2026-10-30

## 背景

原 `service_item` 是一张平铺表，每个服务项目带 S/M/L/XL 四档体型价，开单时按宠物体重自动取档。需求方提供的价目规范（语雀「美容洗护价目表（宠物行业）」）以及参照后台（kadian.bagong.cn「服务 → 洗护美容价目」）采用的是一种不同形态：

- 价目表是「宠物类型 + 筛选条件」为行、「服务分类」为列的价格矩阵；
- 服务分类本身可维护，归入「洗护类 / 美容类」两个大类，可隐藏、可排序；
- 价目表之外另有一份独立的「美容单项」清单，带零售价、折扣和收银台/网店/积分三个开关；
- 折扣支持整批设置，取值为会员组折扣 / 全额 / 9、8、7 折 / 散客组自定义。

两者结构不同，无法在同一张表上演进。

## 决策

1. 删除 `service_item` 及其四档体型价，改为两层结构：**价目行**（宠物类型 + 自定义描述 + 排序，高级筛选标签仅展示）× **服务分类** → **价格格子**。
2. 保留独立的**美容单项**表（名称、分类、零售价、服务折扣、三个开关）。
3. 价目行不参与自动匹配：开单时由收银员手动选行与分类（或直接选美容单项），价格自动带出，可手工改价。
4. 折扣为共用机制，作用于价格格子、美容单项和整单三处；会员折扣需要客户上的**会员组**字段（含散客组，默认 10 折），本轮不改造储值/会员体系。
5. 金额一律以「分」存整数；隐藏的分类保留在价目表列中但不可开单。
6. 价目表、分类、美容单项、批量折扣均仅 `ADMIN` 可修改。

## 后果

- 历史单据按开单时的名称与价格快照保留，不受价目调整影响。
- 开单、预约、次卡适用性中引用旧服务项目的地方需要改为引用价格格子或美容单项。
- 宠物体重自动取档的逻辑下线，开单改为手选；预约转开单不再能按体重预填档位。
- 价格体系（铁牌 / 1000 元档 / 白金卡三档价）本轮不做，后续如需再加。
